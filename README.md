## 原生 IP 到底指什么，这条线为什么算

原生 IP 指 IP 段的注册地和机房实际物理位置一致。日本机房配的就是日本本土运营商分配的段，查 whois 归属地写着 Japan，跟服务器所在地对得上。非原生（广播 IP）则相反：段可能注册在别的国家，只是被广播到日本机房，身份信息和实际住址对不上，风控系统一比对就会警觉。

这个差别对解锁类业务是决定性的。官网对这条线的描述是“冷门小众原生IP，IP纯净，Tiktok运营数据好”，并把解锁范围直接列了出来：TikTok、ChatGPT、Bing AI、Netflix、HULU、DISNEY、Amazon Prime、DMM、TVer、Niconico、FOD(Fuji TV)、Radik、Steam、Spotify、TVBAnywhere+、iQiyi Oversea，以及一批日本本土手游。

网络侧，官网写的是“中国大陆直连优化线路”，并在产品页反复标注“建议开启BBR加速”。架构是 KVM，每款配 1 个 IPv4，自动开通即时交付，官网明示“支持安装Windows”。延迟官网没有公布具体数字，第三方测评提到电信方向均值在 100ms 以内，这只能当参考，不是官方承诺。

**原生 IP 和住宅 IP 差在哪？**
原生讲的是 IP 注册地和机房位置一致，可以是数据中心属性；住宅讲的是 IP 归属家庭宽带运营商，风控眼里像普通日本家庭用户。gid=13 属于前者，gid=37 属于后者，价格差一大截，多付的钱买的是 IP 属性。
